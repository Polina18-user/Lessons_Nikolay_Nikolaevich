# Самостоятельная работа 4 "Нормализация реляционных баз данных"

### Вопросы для выполнения работы
1) Оператор LIKE используется в предложении WHERE для поиска указанного шаблона в столбце.

Есть два подстановочных знака, часто используемых в сочетании с оператором LIKE:

% - Знак процента представляет собой ноль, один или несколько символов
_ - Подчеркивание представляет собой один символ

MS Access использует звездочку (*) вместо знака процента (%) и вопросительный знак (?) вместо подчеркивания (_).

2) Инструкция SELECT TOP используется для указания количества возвращаемых записей.

Синтаксис SQL Server / MS Access:
'''
SELECT TOP number|percent column_name(s)
FROM table_name
WHERE condition;
'''
Синтаксис MySQL:

'''
SELECT column_name(s)
FROM table_name
WHERE condition
LIMIT number;
'''

  `num` INT NOT NULL AUTO_INCREMENT,

  UNIQUE INDEX `num_UNIQUE` (`num` ASC) VISIBLE);

  `id` INT NOT NULL AUTO_INCREMENT,
  `name_pr` VARCHAR(45) NOT NULL,
  `model` VARCHAR(45) NOT NULL,
  `price` DECIMAL(4,2) NOT NULL,
  PRIMARY KEY (`id`),
  UNIQUE INDEX `id_UNIQUE` (`id` ASC) VISIBLE);

CREATE TABLE `sport`.`order` (
  `id` INT NOT NULL AUTO_INCREMENT,
  `id_customer` INT NULL,
  `id_product` INT NOT NULL,
  `quantity` INT NULL,
  PRIMARY KEY (`id`, `id_product`),
  UNIQUE INDEX `id_UNIQUE` (`id` ASC) VISIBLE);
